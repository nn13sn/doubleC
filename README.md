# DoubleC

**An experimental dynamically typed programming language with a custom bytecode virtual machine and an x86-64 JIT compiler.**

DoubleC is an experimental programming language developed from scratch in C++20. The project explores language implementation, runtime design, bytecode execution, and just-in-time compilation.

Unlike a direct implementation of an existing language, DoubleC has its own syntax and semantics. Its execution engine combines a custom bytecode virtual machine with an optional JIT compiler that translates supported functions into native x86-64 machine code.

## Overview

DoubleC currently includes:

- **Lexer and parser** — tokenize and parse DoubleC source code.
- **Semantic analyzer** — perform semantic analysis before execution.
- **Bytecode generator** — translate analyzed programs into custom bytecode.
- **Virtual machine** — execute generated bytecode using a custom runtime environment.
- **JIT compiler** — compile designated functions into native x86-64 machine code at runtime.
- **Runtime system** — handle dynamic values, variables, function calls, and input/output.

Functions marked for JIT compilation can be translated into native x86-64 machine code during runtime.

The project uses **C++20**, **AsmJit**, and **NASM** for its runtime and low-level code generation components.

## Example

```text
function sum(a, b)
{
    return a + b
}

jit function multiply(a, b)
{
    return a * b
}

out(sum(10, 20))
out("\n")
out(multiply(10, 20))
```

More examples are available in the [`examples/`](examples/) directory.

## Getting Started

### Download 

Download the latest release:
[Releases](https://github.com/nn13sn/doubleC/releases)


For more information see 
[Language Documentation](docs/LANGUAGE.md)


### General Requirements

- Linux x86-64
- glibc >= 2.38
- libstdc++ with GLIBCXX_3.4.32 or newer

### Requirements for source build

- C++20-compatible compiler
- CMake 3.16 or newer
- NASM
- Git

AsmJit is included in `external/asmjit`.

### Build

```bash
git clone https://github.com/nn13sn/doubleC.git
cd doubleC

cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build --parallel
```

### Run

```bash
./build/DoubleC program.txt
```

## Project Status

<em>Experimental — under active development.</em>

DoubleC is a work in progress. Its core components, including the bytecode virtual machine and JIT compiler, are implemented, but the language and runtime are still evolving.

**Current platform:** Linux x86-64.
